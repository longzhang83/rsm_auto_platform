# 容诚税务师事务所自动化工具平台 - 项目概览

## 🎯 项目愿景

为容诚税务师事务所打造一个专业、高效、智能的财务自动化工具平台，通过现代化技术提升税务处理效率，降低人工成本，实现财务数字化转型。

## 🏢 企业背景

**容诚税务师事务所**是中国专业的税务服务机构，为客户提供包括税务咨询、税务筹划、税务代理等全方位的税务服务。随着业务量的增长和客户需求的多样化，传统的手工处理方式已经无法满足效率要求。

## 🚀 核心功能模块

### 1. 工作台 (Dashboard)
**目标**: 提供统一的工作入口和数据概览

**功能特性**:
- 📊 实时统计仪表板
- 🎯 快捷工具入口
- 📈 处理趋势分析
- 🔔 重要通知提醒
- 📋 最近处理记录

### 2. 费用清单转凭证
**目标**: 自动化处理费用报销流程

**核心流程**:
```
费用报销表 → 数据解析 → 科目映射 → 摘要翻译 → 凭证生成 → 结果输出
```

**功能特性**:
- 📁 多格式Excel支持 (.xlsx, .xls)
- 🗂️ 智能科目映射
- 🌐 自动摘要翻译
- 📊 批量数据处理
- ⚙️ 灵活的凭证配置

### 3. 摘要翻译
**目标**: 提供专业的中英文摘要翻译服务

**技术特点**:
- 🤖 基于ZhipuAI GLM模型
- 💾 翻译结果缓存
- 🔄 批量并发处理
- 📚 专业术语库管理
- ⚡ 实时翻译预览

### 4. 银行流水转凭证 (开发中)
**目标**: 智能化银行流水处理

**规划功能**:
- 🏦 多银行格式支持
- 🔍 交易类型识别
- 📊 智能分类分析
- ⚠️ 异常交易检测
- 📋 自动科目匹配
