# 银行流水摘要字段一对多映射功能

## 功能说明

银行流水模块现已支持摘要字段的**一对多映射**功能。摘要字段可以配置为多个源字段，系统将按顺序检查每个字段，使用第一个非空值作为摘要。

## 核心特性

- **灵活配置**: 支持单列或多列摘要字段映射
- **智能Fallback**: 按优先级顺序检查字段，自动使用第一个非空值
- **完整支持**: 处理各种空值类型（None、NaN、空字符串、仅空格）
- **向后兼容**: 完全兼容原有的单列摘要映射方式

## 配置方法

### 1. 单列摘要映射（原有方式）

在列名映射配置中，直接指定一个摘要列名：

```
summary: "摘要"
```

系统将从名为"摘要"的列中提取摘要信息。

### 2. 多列摘要映射（新增功能）

在列名映射配置中，使用 `/` 分隔多个列名：

```
summary: "摘要1/摘要2/摘要3"
```

系统的处理逻辑：
1. 首先检查"摘要1"字段，如果非空则使用该值
2. 如果"摘要1"为空，则检查"摘要2"字段
3. 如果"摘要2"也为空，则检查"摘要3"字段
4. 如果所有字段都为空，则返回空字符串

## 实现细节

### 添加的函数

**`_extract_summary_from_columns(row, summary_col_spec, df)`**

该函数负责从DataFrame行中按优先级提取摘要：

- **参数**:
  - `row`: DataFrame行数据（pd.Series）
  - `summary_col_spec`: 摘要列规范字符串（支持/分隔的多列）
  - `df`: 完整的DataFrame，用于验证列是否存在

- **返回值**:
  - 提取到的摘要字符串
  - 如果所有列都为空，返回空字符串

### 修改的函数

**`standardize_bank_statement_data(df, column_mapping)`**

- 第609-614行：使用新的 `_extract_summary_from_columns()` 函数替代原有的简单str.strip()处理
- 第550-577行：增强列验证逻辑，支持多列映射的验证

## 使用示例

### 场景1: 银行流水有多个摘要字段

某银行导出的流水表格包含：
- 摘要1列: 交易类型（可能为空）
- 摘要2列: 交易对方（可能为空）
- 摘要3列: 备注信息

配置：
```python
column_mapping = {
    "date": "日期",
    "summary": "摘要1/摘要2/摘要3",
    "counterparty": "对方户名",
    "bank_account": "银行账号",
    "debit": "借方",
    "credit": "贷方"
}
```

处理结果：
- 交易A: 摘要1="工资" → 使用"工资"
- 交易B: 摘要1="" 摘要2="租金费用" → 使用"租金费用"
- 交易C: 摘要1=None 摘要2="" 摘要3="其他事项" → 使用"其他事项"

### 场景2: 向后兼容

如果仅配置单列：
```python
column_mapping = {
    "summary": "交易摘要",
    # ...其他配置
}
```

系统仍能正常工作，直接从"交易摘要"列提取摘要。

## 空值处理规则

系统将以下情况视为"空"：

1. **None**: Python的None对象
2. **NaN**: pandas的浮点NaN值
3. **空字符串**: `""`
4. **仅空格**: `"   "` （会被自动strip）
5. **字符串"nan"**: `"nan"` （会被特殊识别）

## 性能考虑

- 多列映射仅在摘要列配置中有效，不影响其他字段
- 使用apply()函数处理每一行，对大数据量的性能影响最小
- 列验证仅在数据标准化开始时进行一次

## 常见问题

### Q: 如果一个列名中包含"/"字符怎么办？

A: 由于"/"被用作分隔符，如果列名实际包含"/"字符，目前的实现不支持。建议在银行流水导入前重命名此类列。

### Q: 可以配置4个或更多的摘要列吗？

A: 可以。支持任意数量的列，用"/"分隔即可：
```
summary: "摘要1/摘要2/摘要3/摘要4/摘要5"
```

### Q: 是否影响现有的单列配置？

A: 不影响。完全向后兼容。单列配置仍能正常工作。

### Q: 摘要的顺序很重要吗？

A: 是的，顺序就是优先级顺序。更重要的摘要字段应该放在前面。例如：
```
summary: "主要摘要/备用摘要/备注"
```
