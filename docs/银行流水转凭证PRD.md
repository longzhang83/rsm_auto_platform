# 银行流水转凭证

## 目标

将银行流水数据转化为会计凭证数据，方便企业进行财务核算和报表生成。

## 背景

银行流水数据通常以不同格式存储，缺乏统一的标准，给财务处理带来挑战。通过将银行流水数据转化为标准化的会计凭证格式，可以提高财务处理的效率和准确性。

## 功能需求

1. **数据导入**：支持从Excel导入银行流水数据。
2. **数据清洗**：对导入的银行流水数据进行清洗，格式标准化等。
3. **字段映射**：提供灵活的字段映射功能，将银行流水中的字段映射到会计凭证所需的标准字段。
4. **凭证生成**：根据映射后的数据生成会计凭证，包括凭证日期、摘要、借贷方向等信息。
5. **数据导出**：支持将生成的会计凭证导出为Excel以便后续使用。
6. **日志记录**：记录数据处理的各个环节，便于追踪和审计。

## 会计科目mapping

1. 提供2种方式的会计科目的映射功能
   - 方式一：通过摘要中的关键字映射到会计科目
   - 方式二：通过收付款方名称映射到会计科目
2. 每个客户建立独立的会计科目mapping表

3. 银行科目的mapping规则
   - 银行流水中有 `银行账号` ，去关联：`会计科目mapping` 表中的会计科目，匹配方式：银行账号

## 摘要生成规则

使用银行流水中的“摘要”字段内容。

## 银行流水数据格式标准化

1. 金额列有2中格式： 一种是 借方/贷方 ， 另一种是只有金额列，其中正数表示借方， 负数表示贷方. 需要把金额列标准化为借贷方
2. 收款人名称/付款人名称标准化到对方户名上, 金额属于借方取付款人名称，金额属于贷方取收款人名称
3. 收款人账号/付款人账号标准化到银行账号上, 金额属于借方取付款人账号，金额属于贷方取收款人账号
